# Archived supporting case studies

The bank-risk and SEC-fundamentals case studies are preserved here so the first public release can focus entirely on macro-volatility forecasting.

This material is:

- not sourced by the root `R/` loader;
- not part of the root `targets` graph;
- not exercised by the public test suite;
- retained as a historical snapshot rather than maintained as a standalone package.

The original full pipeline definitions are in `pipeline/`. They document the earlier orchestration but are not expected to run from this archived location without restoring the original layout and private source lake.
