# Archive

This directory preserves material from the repository's earlier multi-project form. It is excluded from the active `targets` graph and public-release tests.

- [`supporting-case-studies/`](supporting-case-studies/) contains the former European bank-risk and SEC-fundamentals code, reports, fixtures, tests, SQL, and figures.
- [`legacy-multi-project-release/`](legacy-multi-project-release/) preserves the former README, pipeline configuration, shared utility snapshot, and generated report set.

Archived macro regularisation results predate the September 2026 `glmnet` penalty-mapping correction and are superseded by the active `results/` and `report/` artifacts. They should not be used as current evidence.

The archive is retained for provenance, not presented as a runnable package. Paths inside historical HTML snapshots may refer to their former repository locations.
